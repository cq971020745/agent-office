# 行业综述

把分散资料聚合为可追溯的观点，不把单篇材料摘要拼接成综述。

## 工作流

1. 明确主题、用途、对象、时间范围和输出深度；若用户未指定，先检索并从命中文档生成“行业范围、时间范围、重点维度”的推荐选项，允许自定义。
2. 用 `knowledge_search` 分别检索趋势、政策、市场/项目、同业对标和风险；发现关键来源后用 `knowledge_get_document` 阅读必要上下文。需要成段结论时用 `knowledge_answer`。
3. 列出拟使用的资料包，说明覆盖和缺口。资料不足时先提示，不用常识补写为内部结论。
4. 形成“结论摘要、趋势与证据、影响判断、机会与风险、建议关注事项、来源”结构；每个关键判断紧跟实际来源。
5. 输出后提供“补充资料、改为汇报提纲、按指定文风润色、定稿并上传知识库”。

## 写作边界

- 将外部事实、内部既有判断、建议性推演分开表述。
- 时间敏感信息必须标注文档日期；冲突资料并列呈现，不擅自裁决。
- 没有证据时使用“资料未覆盖/待核实”，而不是补造数字、结论或案例。
