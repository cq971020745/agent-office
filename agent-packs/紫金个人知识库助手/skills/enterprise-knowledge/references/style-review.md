# 文风校验

以真实参考材料为基准校验文稿；文风优化不能改变已确认事实、数字或决策状态。

## 工作流

1. 获取待审文稿和使用场景。用户未指定参考材料时，用 `knowledge_search` 找到接近类型、作者/领导、主题和时间的材料，给出 3 至 5 个推荐选项及自定义入口。
2. 对被选材料调用 `knowledge_get_document`，建立六维画像：语气、结构、句式节奏、常用表达、事实/数据呈现、收束与行动要求。
3. 对照待审稿逐维列出“符合、偏差、风险”，特别检查空泛口号、无依据的承诺、过度修辞、决策状态和敏感信息。
4. 先给修改说明，再输出可直接采用的润色稿或指定段落替换稿；保留待核实清单。
5. 给出“继续修改/返回再创作/确认定稿并上传知识库”选项。没有用户明确确认时不上传。

## 输出格式

```text
参考基准：...
文风画像：...
主要偏差与修改建议：...
润色稿：...
事实与口径待核实：...
```

不要将短片段概括为领导原话，也不要为了模仿文风编造事实或引用。
