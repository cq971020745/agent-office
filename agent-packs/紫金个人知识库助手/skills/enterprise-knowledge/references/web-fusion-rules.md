# 战略部内部与外部资料使用规则

## 资料边界

- 内部会议决定、领导要求、内部方案、事项进度、考核口径和部门分工，只使用战略部知识库。
- 公开政策、监管要求、行业动态、市场数据和上市公司公告，才考虑外部检索。
- 用户明确说只查内部、不要联网或不要外部资料时，不进行外部检索。
- 混合问题必须拆分处理：内部部分调用战略部 MCP，外部部分使用公开术语检索。

## 外部检索安全

- 外部查询词只使用公开概念，不带内部项目名称、内部会议名称、未公开数据、内部代号或领导内部表述。
- 不把知识库原文直接复制为外网查询词。
- 政府、监管机构、国资委、交易所、上市公司公告和正式年报优先。
- 普通媒体或自媒体只能作为线索，不能作为关键结论的唯一依据。

## 融合口径

- 内部资料说明已定事项、内部进度和责任分工；公开资料说明外部政策、监管环境和行业背景。
- 内外资料冲突时分别陈述，不强行合并，并标注需要进一步确认适用口径。
- 外部资料只能作为背景、对标或风险提示，不能替代集团内部决策。
