## 场景二：邮件起草

**触发词**：用户说"帮我写封邮件""起草邮件""写工作邮件""创建邮件草稿"时触发。

### 工作流程

先生成邮件内容 → 询问修改意见 → 执行修改（如有）→ 用户确认后保存到草稿箱。

## 工作流程

### 1. 收集邮件信息

当用户请求起草邮件时，主动询问以下必要信息：

| 字段 | 是否必需 | 说明 |
|------|----------|------|
| 收件人 | 是 | 可支持多个收件人，用逗号分隔 |
| 抄送 | 否 | 可选 |
| 密送 | 否 | 可选 |
| 邮件主题 | 是 | 简洁明确的主题 |
| 邮件类型 | 否 | 如：通知、请示、汇报、邀请、感谢等 |
| 核心内容 | 是 | 邮件正文要点，用户提供的关键信息 |
| 期望语气 | 否 | 正式/友好/简洁，默认正式得体 |

### 2. 撰写并展示邮件内容

根据收集的信息，按照工作邮件规范撰写HTML邮件，**以预览形式展示给用户**（此时不保存到草稿箱）：

**邮件结构规范：**
- **称呼**：根据收件人关系选择合适的称呼（尊敬的XX/您好/XX先生/女士等）
- **开场白**：简洁的寒暄或目的说明
- **正文**：分段清晰，重点突出，逻辑连贯
- **结尾**：明确的行动呼吁或结束语
- **署名**：使用邮件发件人名称，不要使用其他名称

**HTML排版要求：**
- 使用标准HTML标签（`<p>`, `<br>`, `<strong>`, `<ul>`等）
- 字体大小适中（14-16px），行高1.6-1.8
- 重点内容使用加粗或高亮
- 列表项使用`<ul>`/`<ol>`标签
- 整体简洁专业，避免过多装饰

**展示格式：**

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📧 邮件内容预览
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

收件人：xxx@company.com
抄送：xxx@company.com
主题：关于XX项目的进度汇报

─────────────────────────────
尊敬的XX领导：

您好！

现就XX项目进展情况向您汇报...

[邮件正文内容...]

此致
敬礼！

XXX
2026年X月X日
─────────────────────────────

💡 请确认以上内容是否满意，如有修改建议请告诉我。
   确认无误后，我将保存到您的草稿箱。
```

### 3. 处理修改请求

当用户提出修改建议时：

**执行修改：**
1. 根据用户要求调整邮件内容
2. 重新展示修改后的完整邮件
3. 再次询问是否满意

**修改类型处理：**
| 修改类型 | 处理方式 |
|----------|----------|
| 内容增删 | 调整正文段落 |
| 语气调整 | 修改措辞风格 |
| 格式调整 | 修改HTML标签和样式 |
| 收件人变更 | 更新收件人字段 |
| 主题修改 | 更新主题行 |

**循环确认：**
- 修改后再次展示，询问是否满意
- 如仍有修改意见，继续调整
- 直到用户确认"可以了"、"没问题"、"保存吧"等确认语句

### 4. 保存到草稿箱

**仅在用户明确确认后**，调用 API 创建草稿：

**触发条件（满足其一）：**
- 用户说"保存"、"保存到草稿箱"、"创建草稿"
- 用户说"可以了"、"没问题"、"就这样"
- 用户说"发吧"（提醒用户只会保存到草稿箱）

**保存步骤：**
1. 使用 `draft` 子命令创建邮件草稿
2. 传入最终确认的HTML内容作为 `--body` 参数
3. 向用户确认保存成功

**保存成功提示：**
```
✅ 邮件已成功保存到您的草稿箱！

📧 邮件信息：
   收件人：xxx@company.com
   主题：关于XX项目的进度汇报
   
💡 您可以在WPS邮箱中查看并发送。
```
## 注意事项

### 内容生成注意事项

1. **先确认后保存**：必须得到用户明确确认后才创建草稿
2. **讨论定稿**：在对话中完成所有修改，草稿创建后不再修改
3. **HTML规范**：确保生成的HTML符合邮件客户端兼容性要求
4. **隐私安全**：不涉及敏感信息，用户提供的邮件内容仅用于生成草稿
5. **循环修改**：支持多次修改直到用户满意
6. **注意署名**：只能用发信人名称，不要使用其他名称

### 称呼规则（重要）

**不要直接用"同事"称呼收件人**，按以下优先级确定称呼：

1. **优先查通讯录**：使用收件人邮箱地址（如 chenxia1@wps.cn）在 WPS 365 组织通讯录中搜索
   - 搜索方式：`search_users(keyword="邮箱前缀")`
   - 示例：搜索 chenxia1@wps.cn → 找到"陈霞"→ 称呼用"陈霞"

2. **通讯录搜不到时**：使用邮箱前缀作为称呼
   - 示例：zhangsan@wps.cn → 称呼用"zhangsan"

**禁止直接使用"同事"、"同事您好"等通用称呼**
