# 0002 - 任务在服务端执行，客户端只是控制台

产品形态对标 WorkBuddy，但其桌面版实际是「本地执行 + 云端长任务」混合体，且本地执行派产品（Claude Code、Codex CLI、OpenClaw）一律用本地 SQLite/JSONL 存会话，没有集中式 SQL 先例。我们的既定约束是前后端分离 + Vue + MySQL，只有服务端执行模式下三者自洽，故决定：**pi 内嵌在 Node 后端，每个任务在服务器上的任务工作区中执行，成果物存服务器、客户端下载验收**。本地文件能力以「上传到任务工作区 / 下载成果物」替代；「电脑保持开机」的约束消失；任务可关机续跑。二期若需本地文件操作，可加 WorkBuddy 式本地执行位（pi 是 TS 库，客户端 Electron main 进程同样能嵌），架构上已预留。

## Consequences

- 每任务一个独立工作区目录（MVP），代码执行类工具上线时升级为每任务一个容器（pi 官方无权限系统，隔离靠容器，见其 containerization 文档）。
- 客户端壳选 Electron + Vue 的理由弱化为「托盘/通知/分发体验」，若某天不需要桌面形态，Web 端可直接复用同一后端。
