# 本应用登录采用企业知识库用户，紫金协作挂在该用户上

本应用不再维护一套自行注册的账号。登录身份就是企业知识库用户；紫金协作只作为这个用户同步下来的 WPS 用户信息。三套账号各存一份密码会对不齐部门和停用状态，而企业知识库已经是带部门、岗位和角色的组织目录，紫金协作也不是它的登录来源。

同一个人先用手机号认定：知识库侧手机号不重复，且多数登录账号就是手机号。两边都是完整 11 位且不一致时不关联。手机号为空或脱敏时，仍保存用户明确同步来的紫金协作用户编号。

本应用的管理员只对应企业知识库角色里的超级管理员，其余企业知识库用户都是成员。部门管理员的数据权限留在企业知识库，不因此进入本应用管理后台。

改登录方式时，自行注册的旧账号及其任务、成果物、定时巡检和已缓存的 WPS 用户信息删除。专家和技能没有归属用户，予以保留。左侧嵌入企业知识库现有工作台，供当前用户使用知识空间、文档和问答，不在本应用重做，也不嵌入用户管理。知识库页面把登录态放在 localStorage，因此由本服务把 `/new-general-rag-kb` 代理到知识库，并在首个 HTML 响应里写入该用户的访问凭证。桌面页的 `frame-src` 必须放行 API 源，否则工作台是空白页。
