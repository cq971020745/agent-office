# 模型供应商属于企业知识库用户，不在管理后台共用

每个企业知识库用户自己配置模型供应商、密钥和启用的模型。管理后台不再维护一份全员共用的供应商。专家不保存供应商、密钥或默认模型名；派发任务时，用户从自己启用的模型里选择。定时巡检在创建时记下所属用户选定的供应商和模型，到点按这份调用。远端语音转写只使用该用户供应商上绑定的语音模型；没有绑定时用平台本地引擎。尚未配置模型供应商的用户不能派发任务。

切换前已经存在的全局供应商和密钥，整份交给唯一的超级管理员，成为他个人的模型供应商。其他用户从空配置开始自己添加。不把密钥继续留在后台共用名单里，是因为每个用户都要配置自己的模型，而密钥不该被复制给所有人。
