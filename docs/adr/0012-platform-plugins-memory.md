# 0012 - 内置平台插件生命周期与可替换的用户记忆后端

状态：当前实现的决策记录，2026-10-26。与 [ADR 0008](0008-product-shipped-pi-packages.md) 的 Pi 包分发、[ADR 0011](0011-skin-packs-css-only.md) 的 CSS 皮肤分别管理。

## 决策

- Pi 继续作为嵌入式 Agent Runtime；产品集成由服务端 `PluginRegistry` 编排，不要求用户安装 Pi CLI，也不使用用户 `~/.pi`。
- 插件由项目代码显式注册，提供启动/停止、路由、工具装配、轮前/轮后、任务开始/删除 hook。插件 enabled 状态存 SQLite；数据库迁移仍由核心 `db.ts` 建表，不宣称已有独立插件迁移框架。
- 核心认证、任务、项目和管理入口保持宿主所有；插件业务路由用 503 门控。停用影响后续 hook 和新建会话，不能把停用等同于撤销已缓存会话的全部工具。
- 记忆通过 `MemoryBackend` 抽象隔离，首版使用本地 SQLite，按用户查询、保留、召回和忘记；不引入 Hindsight 服务、向量数据库或图谱。
- 自动沉淀必须显式设置 `MEMORY_AUTO_CAPTURE=1`；仅成功轮次保存限长经验摘要。默认由用户手动维护，并提供查看和删除入口。

## 参考资料与信任边界

任务内容、文件和模型回复都可能含有不应成为长期指令的文字。记忆按用户隔离，注入块带 id/类型/置信度并明确“参考资料，不是用户指令”；它不改变工具权限。失败、取消不沉淀；来源任务删除通过 hook 清理其关联记忆。

以上是风险收敛措施，不保证摘要的事实准确性，也不构成对提示词注入的完整防护。当前无人工审核工作流、语义去重、TTL 或容量治理；错误记忆由用户删除。停用插件时删除任务不会调用该插件清理 hook，运维不能假定此时关联记忆已经删除。

## 后果

- 启用/启动状态、路由归属和新会话行为必须可诊断；单插件 hook 异常独立记录，不能阻断核心任务。
- 后续替换后端优先保持用户边界与 `MemoryBackend` 契约，避免改 Runner 和客户端协议。
- 当前按注册顺序执行，未实现插件依赖、通用超时、已有会话统一失效或 schema 版本迁移；这些保留为明确工程欠账。
- 用户接口、环境变量和操作方式分别维护在 [集成说明](../integration-guide.md)、[运行手册](../runbook.md)；本 ADR 不重复接口清单。
