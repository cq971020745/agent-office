# 交接状态

核对日期：2026-10-26。本文记录当前代码与本次验证边界；不替代 [架构](design.md) 或 [运行手册](runbook.md)。

## 已完成

- 平台注册 10 个内置服务端插件，提供持久化启停、状态列表、管理员入口、路由 503 门控和 Runner 生命周期接入。
- 长期记忆支持用户隔离、手动创建/查看/删除、中文片段召回和来源任务关联；自动沉淀默认关闭，仅显式开启时保留成功轮次经验摘要。
- CSS 皮肤包支持内置差异同步、上传/导出、任务生成后安装、本服务器/npm/GitHub 市场；不加载皮肤 JavaScript。
- 桌面支持保存中心服务地址，远程模式跳过本机内置服务启动；渲染层按所选服务补充资源 CSP 源。
- 增加 Windows CI 类型检查与服务端测试；服务端测试改为逐文件执行，任一失败即退出。
- 0.1.5 云端业务服务已上线，独立 systemd 用户与数据目录、开机自启、nginx 平滑代理均已配置。入口与回滚位置见 [部署记录](deployment-0.1.5.md)。

## 已知体验缺口

- 首页模型空状态仍要求管理员添加，与个人供应商模式不一致。
- 记忆页介绍默认自动沉淀，但真实开关默认关闭。
- 追问发送前清空文本，失败分支不恢复输入；草稿只在页面内存中。
- 巡检表单不支持选择供应商和模型，后端接口虽支持，未显式指定时使用所属用户可用配置。
- 本地一体包没有托盘常驻；关闭最后一个窗口会停止内置服务。独立服务或远程服务不受该窗口关闭影响。
- 成果物无版本快照和独立验收状态，DOCX/XLSX/PPTX 无页级预览。

候选改进与 UI 范围在 [产品与 UI 待办](product-roadmap.md)，均未因文档同步而自动转为已实现或已承诺需求。
