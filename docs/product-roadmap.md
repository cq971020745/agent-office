# 产品与 UI 候选改进

来源：2026-10-26 项目代码与历史截图审视。以下是建议优先顺序，尚未批准逐项实施；本次仅同步文档，不改变产品行为。正式排期前应结合真实用户任务与客户端实测收窄范围。

> 2026-10-27：下表五项体验修复已在 `feat/muniu-liuma-client-pack` 分支实现，待合并与真机验收；「功能候选」「UI 候选」仍未排期。

## 优先补齐现有体验

| 问题 | 建议行为 | 核对入口 |
| --- | --- | --- |
| 首页模型提示指向管理员 | 引导用户配置自己的模型供应商 | `HomeView.vue` |
| 自动记忆文案与默认开关冲突 | 展示实际捕获开关，关闭时解释手动添加 | `MemoryView.vue`、`plugins/memory.ts` |

## 功能候选

| 优先级 | 能力 | 可验收的目标 |
| --- | --- | --- |
| 高 | 成果物版本与验收 | 修改后仍能查看前版；支持待验收、需修改、已验收及反馈；与执行状态分开 |
| 高 | 跨任务成果物中心 | 按项目、类型和日期找文件，支持批量下载与回到来源任务 |
| 高 | 草稿与失败恢复 | 切页或重启后找回草稿；区分模型、连接器、权限失败并给出对应操作 |
| 高 | 首次使用引导与统一自检 | 从企业登录、个人模型配置到首个任务有清楚下一步；汇总集成状态与修复入口 |
| 高 | 全局通知中心 | 切换任务后仍能看到完成、失败、待确认，点击回到对应任务 |
| 中 | 参数化场景模板 | 保存成功任务为模板，输入时间范围、对象和成果格式后复用；不重复另建技能机制 |
| 中 | Office 预览与选段反馈 | 文档按页、表格按工作表预览，针对选中内容继续修改 |
| 中 | 巡检运行治理 | 运行历史、失败原因、工作日规则、重复执行控制和有变化才通知 |
| 中 | 可解释记忆 | 展示本轮参考的记忆，可排除或纠错；支持搜索、编辑、停用和项目范围 |
| 后续 | 用量与耗时 | 统计耗时和 Token，价格信息明确后再计算估算费用 |

## UI 候选

- 首页：保留派发输入框，增加待确认、继续任务和常用模板；统计信息降低权重。
- 专家入口：输入框旁直接显示当前专家，“+”以附件和引用为主，减少二级菜单发现成本。
- 侧栏：按任务/项目/成果物、能力配置、个人设置、管理员入口分组；项目仍只代表用户显式自选目录。
- 任务详情：显示当前步骤、等待原因和用户所需操作；工具轨迹折叠，子专家有独立状态摘要，不伪造完成百分比。
- 审批：先展示人能理解的影响范围和对象，命令/JSON 作为详情；保留仅本次、本会话和拒绝语义。
- 小窗口与键盘：自动收起预览和次要工具、提供字号/密度设置，统一弹窗焦点与 Esc 行为；视觉改动需另做运行态检查。

## 约束

继续复用企业知识库工作台，不重建账号或知识库页面；模型密钥和连接器仍按用户隔离；专家包技能不进入全员库；皮肤只允许 CSS 与静态资源。任何模板、协作或检索增强都不得突破这些现有边界。
