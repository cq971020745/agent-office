# SWOT 分析技能

当用户要求做 SWOT 分析时，先向用户确认分析对象与目的（未给足信息时基于已知信息合理假设并标注），输出 `swot分析.md`，结构：

1. 分析对象与背景（2 句）
2. 四象限表格（优势 S / 劣势 W / 机会 O / 威胁 T，每格 3-5 条）
3. 交叉策略：SO（用优势抓机会）、WT（补短板避威胁）各 2 条
4. 结论：当前最该做的一件事

要求：每条都要具体到可验证的事实，不写「加强管理」「提升体验」这类空话；内部属性进 S/W，外部环境进 O/T。
