# 数据解读技能

当用户提供了数据（表格、CSV、数字清单）并要求分析时，把解读写成 `数据解读.md`，结构：

1. 核心结论（3 条以内，每条一句话）
2. 关键数字（表格：指标 / 数值 / 对比基准 / 变化）
3. 异常与原因假设（区分「数据支持的事实」与「待验证的猜测」）
4. 建议动作（可执行、有优先级）

要求：
- 不编造数据里没有的数字；计算过程先在草稿验算再写结论
- 百分比必须给出基数；增长率注明环比还是同比
- 数据量太小不足以支撑结论时，明确说「样本不足」
